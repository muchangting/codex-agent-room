# Changelog

## 0.2.0

- Added a light, green-accented messenger interface with group avatars and self-aligned message bubbles.
- Added a collapsible group information panel with member roles and expandable task cards.
- Added sanitized Markdown for lists, links, tables and code blocks.
- Added member mentions, a create-group dialog, narrow layouts and keyboard focus styles.
- Vendored the required Agent Chat sources so the plugin no longer depends on a sibling checkout.
- Added generated local configuration, environment-based Gemini credentials, an installation guide and CI configuration.

## 0.1.0

- Adapted Agent Chat as an MCP Apps panel for Codex.
- Added persistent local rooms, real Gemini task execution and explicit Codex acceptance.
